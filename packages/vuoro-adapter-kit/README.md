# vuoro-adapter-kit

`vuoro-adapter-kit` contains the dependency-free boilerplate shared by Vuoro
domain adapters: strict Draft 2020-12 object-schema construction, immutable
operation metadata, and the structural catalog registry protocol. It does not
depend on `vuoro-service`, Pydantic, JSON Schema validators, or any domain
package. Owners remain responsible for their operation schemas and handlers.
